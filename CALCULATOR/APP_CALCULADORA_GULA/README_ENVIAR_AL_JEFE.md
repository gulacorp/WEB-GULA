# GULA Calculadora - App portable

## Opción más simple

Envía el archivo `index.html` de esta carpeta. Tu jefe puede abrirlo con Chrome, Edge o Safari haciendo doble clic. No necesita instalar nada y los datos van dentro del HTML.

## Opción tipo app en Android

1. Sube esta carpeta a Drive, Dropbox, servidor interno o envíala comprimida.
2. Abre `index.html` desde Chrome.
3. En Chrome, usa `Añadir a pantalla de inicio` o `Instalar app`.
4. Después se abre como una app y funciona offline cuando ya se haya abierto una vez.

## Exportar datos visibles

Dentro de la calculadora hay dos botones:

- `Exportar CSV`: descarga una tabla con los cálculos actuales.
- `Exportar HTML visible`: descarga una copia HTML con los datos y el estado actual para reenviar.

## Nota sobre APK

Un APK real requiere empaquetarlo con Android Studio, Capacitor o Bubblewrap y firmarlo. Esta carpeta es una app web instalable y portable, que es la opción más rápida para enviarla y que funcione sin tocar inventario.
